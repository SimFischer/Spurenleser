# Illustrationen

Alle SVGs wurden eigens für Spurenleser erstellt, ohne externe Bilder oder Schriften. `backgrounds/harbor.svg` ist die Hafenillustration, `objects/watch.svg` die Fallkarte, `ui/compass.svg` das Markenzeichen. Für spätere Figurenillustrationen kann `characters/` ergänzt werden. Dateien lassen sich bei gleichen Pfaden austauschen; Bildbeschreibungen in `index.html` und `js/app.js` anpassen. Keine Laufzeitdownloads.
